# Kelulusan SMAN 1 Plakat Tinggi 2025

📢 **Pengumuman Kelulusan Peserta Didik SMAN 1 Plakat Tinggi Tahun Ajaran 2024/2025**

Website ini dibuat untuk menampilkan hasil kelulusan peserta didik secara online. Siswa dapat melihat status kelulusan mereka dengan memasukkan NISN pada halaman utama.

🕒 Pengumuman resmi dibuka pada:
**5 Mei 2025, pukul 22.00 WIB**

---

## 🔗 Akses Website

**[Klik di sini untuk membuka halaman kelulusan](https://sman1plakattinggi.github.io/kelulusan-sman1-2025)**
